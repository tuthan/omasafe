What changed in v0.2.1

From “what is installed?” to “what can it reach?”

OmaSafe keeps the local trust layer small and makes the review surface legible: every result carries identity, evidence, and coverage.

01 / analyze

See the whole payload.

Inventory QML, JavaScript, shell, Python, binaries, modes, digests, invocation edges, and explicit coverage limits.

02 / review

Review the exact change.

Inspect rule-backed findings, capability context, marketplace claims, and candidate updates before native mutation.

03 / control

Keep the decision yours.

Advisory and hardened policies, scoped suppressions, exact expiring overrides, and report-only scheduled scans.

Scope

Four questions, answered before trust

identity

What is installed?

Repository, HEAD, tree OID, dirty worktree.

provenance

Is it what was checked?

Correlated against a commit-pinned catalog.

drift

What changed since?

Your baseline, a diff, a daily quiet sweep.

review

What should I read?

Payload and capability evidence.

Roadmap

Ordered by dependency, not ambition

The analyzer is bounded and evidence-first. Lifecycle controls stay opt-in, explicit, and reportable.

Boundaries

What it will never claim to be

  • Antivirus, sandboxing, or EDR
  • A universal security score
  • A promise to stop every malicious plugin
  • Automatic privileged remediation
  • A hosted reputation service
  • Affiliated with or endorsed by Omarchy

Getting started

Download the engine, then review what you trust

Install the signed v0.2.1 CLI from GitHub, inspect a plugin's payload, and keep the optional Omarchy bar widget separate in the OmaSafe plugin repository.

Download the CLI release Installation instructions
verified install
curl --fail --proto '=https' --tlsv1.2 --location \
  https://raw.githubusercontent.com/tuthan/omasafe/v0.2.1/scripts/install-cli.sh \
  | bash -s -- --version latest

# exact release
curl --fail --proto '=https' --tlsv1.2 --location \
  https://raw.githubusercontent.com/tuthan/omasafe/v0.2.1/scripts/install-cli.sh \
  | bash -s -- --version v0.2.1
analyze & review
omasafe-cli plugins trust PLUGIN_ID --yes \
  --expected-head HEAD --expected-tree TREE

omasafe-cli plugins analyze PLUGIN_ID --format json
omasafe-cli plugins review-update PLUGIN_ID \
  --expected-commit COMMIT
omasafe-cli schedule install --policy advisory
