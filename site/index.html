Scope

Four questions, answered after install

identity

What is installed?

Repository, HEAD, tree OID, dirty worktree.

provenance

Is it what was checked?

Correlated against a commit-pinned catalog.

drift

What changed since?

Your baseline, a diff, a daily quiet sweep.

review

What should I read?

Payload and capability evidence.

Roadmap

Ordered by dependency, not ambition

Identity and diff before the analyzer. The analyzer's report contract before anything privileged.

v0.1

Local plugin trust

Inventory, catalog correlation, commit identity, baseline, diff, drift alerts.

Released · signed CLI
v0.2

Capability analyzer

QML-aware parsing, payload edges, sensitive shell APIs, reviewed updates.

v0.3

AUR review

PKGBUILD static analysis and update diffs, never executing a build file.

v0.4

Posture regressions

LUKS, firewall, SSH, persistence surfaces. Change state, not a grade.

v0.5

Narrow remediation

Per-action polkit helper, first hardening installer, report export.

later

Held

Secrets sweep, panic workflow, VirusTotal hash lookups, AIDE.

Boundaries

What it will never claim to be

  • Antivirus, sandboxing, or EDR
  • A universal security score
  • A promise to stop every malicious plugin
  • Automatic privileged remediation
  • A hosted reputation service
  • Affiliated with or endorsed by Omarchy

Getting started

Download the engine, then pin what you trust

GitHub releases are the first distribution path. The optional Omarchy bar widget is maintained and installed separately in the OmaSafe plugin repository.

Download the CLI release Installation instructions
verified install
curl --fail --proto '=https' --tlsv1.2 --location \
  https://raw.githubusercontent.com/tuthan/omasafe/d4fb76d/scripts/install-cli.sh \
  | bash -s -- --version latest

# exact release
curl --fail --proto '=https' --tlsv1.2 --location \
  https://raw.githubusercontent.com/tuthan/omasafe/d4fb76d/scripts/install-cli.sh \
  | bash -s -- --version v0.1.2
pin & watch
omasafe-cli plugins trust PLUGIN_ID --yes \
  --expected-head HEAD --expected-tree TREE

omasafe-cli plugins diff PLUGIN_ID
omasafe-cli schedule install   # daily sweep
