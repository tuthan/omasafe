# Arch packaging preparation

M7 provides a source-build `PKGBUILD` for the `omasafe-cli` binary. It is intended
for clean-checkout validation and local package testing; it is not being published
to the AUR yet. The Omarchy UI is maintained as a separate marketplace plugin and
is not installed by this package.

The package installs the `omasafe-cli` binary, generated man page, and generated
Bash, Zsh, and Fish completions without creating a persistent service unless the
user explicitly runs `omasafe-cli schedule install`.

The `PKGBUILD` must build from a tagged source tree and `Cargo.lock`, keep package
contents deterministic, preserve the documented XDG state/cache behavior, and
include a `package()`-time file manifest suitable for the M7 self-inventory report.

The generated assets are defined by `docs/cli-surface.txt` and regenerated by
`scripts/generate-cli-assets.sh`. Run the script with `--check` in CI to detect
stale committed output.

Before any AUR publication, replace the temporary `sha256sums=('SKIP')` entry with
the verified source-tarball checksum and complete the clean-build, install,
upgrade, and uninstall validation.
